# Household Budget PWA v8 — compact

Mudança principal:
- removido o bloco **Progress & Trend**;
- mais espaço vertical para os Spending Targets e o resumo principal;
- mantidos Total Budget Progress e as categorias.

Para atualizar no GitHub Pages:
1. substitua o `index.html` do repositório por este arquivo;
2. mantenha `manifest.webmanifest`, `sw.js`, `netlify.toml` e `README.md`;
3. faça Commit changes;
4. aguarde o GitHub Pages publicar novamente;
5. no iPhone/iPad, feche e reabra o PWA; se o cache persistir, abra a URL no Safari e atualize a página.
